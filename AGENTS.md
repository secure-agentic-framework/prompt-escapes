# Prompt Escapes

A local security learning lab built around an AI travel booking simulator, inspired by OWASP Juice Shop.

Use `bd` for issue tracking. Run `bd ready --json` before claiming work.

This is a local-only Python standard-library app. Run `python3 -m unittest discover -s tests -v` and `node --check static/app.js` for changes to behavior. Keep all prices in integer USD cents. Booking authority belongs to the server and explicit UI approval, never model output. All inventory is fictional. Do not commit API keys or runtime databases.
